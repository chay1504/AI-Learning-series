# Case Studies & Breakdowns

Research, transcripts and scripts for **Tech Boy Deepak's case-study / breakdown videos** on YouTube ([@tech.boy.deepak](https://www.youtube.com/@tech.boy.deepak/videos)): industry explainers, business breakdowns and "what's really happening" videos.

This branch is **separate from the AI Learning Series**. The AI Learning Series scripts, notebooks and teaching-style research live on their own branch (`claude/peaceful-euler-tmj2fb`) and are not included here.

## Layout

```
transcripts/   Reference videos: Telugu original + English translation, timestamped
```
