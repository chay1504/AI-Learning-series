# Curriculum Plan — Phase 3: Days 21–35, Deep Learning Foundations

_Transcribed from the planning screenshot shared by the user._

> **Goal of this phase:** help viewers understand what's happening inside a neural network before they learn how modern LLMs are built.
>
> Earlier note in the plan: "For Days 7–8, keep the explanations conceptual. You'll return to the technical details of LLMs in Phase 3."

| Day | Video topic | Subtopics to cover |
|---|---|---|
| 21 | What is Deep Learning? | Neural networks, why deep learning matters, real examples |
| 22 | What is an artificial neuron? | Inputs, weights, bias, output; a hand-drawn neuron |
| 23 | How does a neural network work? | Input layer, hidden layers, output layer |
| 24 | What are weights and biases? | How they affect predictions, intuitive examples |
| 25 | What is an activation function? | Why neurons need nonlinear functions; ReLU and sigmoid |
| 26 | What is a loss function? | Measuring prediction error, simple examples |
| 27 | What is gradient descent? | Adjusting parameters to reduce error |
| 28 | What is backpropagation? | How errors help update weights; conceptual explanation |
| 29 | What are epochs, batches and learning rates? | Training terminology, practical effects |
| 30 | Build a neural network | Train a simple model using a beginner-friendly framework |
| 31 | What is computer vision? | How AI processes images; image classification examples |
| 32 | What is a CNN? | Filters, feature maps, pooling, image recognition |
| 33 | What is NLP? | Text processing, language tasks, practical applications |
| 34 | RNN vs. LSTM vs. Transformer | How architectures process sequences; why Transformers matter |
| 35 | Build an image classifier | Dataset, training, testing and prediction demo |

> **Teaching tip (from the plan):** Days 22–29 should use drawings. A neural network diagram is much more useful for beginners than starting with equations.

## Scope of this work (as requested)

Two videos, covering Days 21–28 only:

- **Video A — "Inside a Neural Network"**: Days 21–24 (What is DL, artificial neuron, how a NN works, weights & biases)
- **Video B — "How a Neural Network Learns"**: Days 25–28 (activation function, loss function, gradient descent, backpropagation)

Days 29–35 are intentionally left for later.
