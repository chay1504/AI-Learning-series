## 4. Roles inside a game studio (who ships a big game)

**Typical team composition (ballpark only, no industry census):** art **~30–50%**, engineering **~20–35%**, QA **~10–20%**, design **~5–15%**, production **~5–10%**. Programmers are often around 20% of a team. Art is consistently the largest department. [U] https://kevurugames.com/blog/game-development-team-structure-average-team-sizes-and-production-statistics/ ; https://userpages.cs.umbc.edu/olano/class/493-25-2/roles.md.html

| Dept | Role | One-line description |
|---|---|---|
| **Design** | Game designer / creative director | Defines the core idea, the rules, and what makes the game fun |
| | Level designer | Builds maps and missions: layout, pacing, where enemies and rewards go |
| | Systems / combat designer | Designs the mechanics: weapons, skills, progression, balance numbers |
| | Narrative designer / writer | Writes the story, dialogue, and quests, and how players experience them |
| | UX / UI designer | Designs menus, HUD, and controls so the game is easy to understand |
| | Economy / monetisation designer | Designs in-game currency, battle passes, and the store (live-service games) |
| **Engineering** | Gameplay programmer | Turns design into code: movement, combat, AI behaviour, missions |
| | Engine programmer | Builds and maintains the core engine (Unreal, Unity, RAGE, etc.) |
| | Graphics / rendering programmer | Lighting, shaders, and performance that make visuals look real |
| | Tools programmer | Builds the in-house tools that artists and designers use every day |
| | Network / online programmer | Multiplayer, servers, matchmaking, anti-cheat |
| | AI programmer | NPC and enemy decision-making, pathfinding, crowd systems |
| **Art** (largest dept) | Concept artist | Paints the first look of characters, worlds, and props |
| | 3D environment artist | Models cities, terrain, buildings, props |
| | Character artist | Sculpts heroes, NPCs, creatures |
| | Technical artist | The bridge between art and code: shaders, rigs, pipelines (hard to hire) |
| | Animator | Makes characters move: hand-keyed plus motion-capture cleanup |
| | VFX artist | Explosions, fire, magic, weather |
| | Lighting artist | Sets mood and readability with light |
| | Cinematics | Cutscenes, camera, mo-cap direction |
| **Audio** | Sound designer | Every footstep, gunshot, and ambience |
| | Composer | Original music score |
| | Voice director / dialogue team | Casting and recording voice actors, in many languages |
| **Production** | Producer / executive producer | Owns schedule, budget, and team. Gets the game shipped |
| | Project manager / scrum master | Tracks tasks and milestones across hundreds of people |
| **QA** | QA tester / QA analyst | Plays builds repeatedly to find and log bugs. Often a large, outsourced group |
| | Test automation engineer | Writes automated tests and bots |
| **Live / business** | LiveOps team | Runs seasons, events, and updates after launch |
| | Data analyst | Studies player behaviour, retention, and spending |
| | Community manager | Talks to players on Discord, social media, and forums |
| | Localisation | Translates and culturally adapts text and voice (Telugu, anyone?) |
| | Marketing / PR / UA | Trailers, campaigns, influencer deals, user acquisition |
| | Outsourcing / co-dev partners | External studios, often in India, China, and Eastern Europe, doing art, QA, and porting. (Rockstar India, ~1,615 staff reported on GTA 6, began as an outsourcing/art studio) [U] |

## 6. Disputed / uncertain: handle carefully on camera

- **Market caps (Nov 2026):** not verified for Tencent, Sony, Microsoft, NetEase, Take-Two or Krafton. Pull live from companiesmarketcap.com on recording day. The Take-Two cap after the GTA 6 rally is unknown.
- **Microsoft gaming FY2026 dollar total:** sources disagree on whether "-$1.7B / -7%" is total gaming or hardware. Total gaming is the more likely reading. The ~$21.8B figure is derived from a FY2025 base of ~$23.5B (from memory, re-check in the 10-K).
- **Xbox headcount:** "~16,000" is inferred from "3,200 = 20%". It is not stated.
- **EA headcount:** ~13–14.5k. The 3%/400-job report is undated in my results. EA is private now, so there are no new 10-K filings.
- **Rockstar headcount and the GTA 6 team of ~5,900:** fan-site and aggregator data, not official.
- **Concord budget:** ~$200M+ vs ~$400M. Both are unconfirmed.
- **Spider-Man 2 $315M:** from a hacker leak (Insomniac ransomware, Dec 2023), not an official disclosure.
- **TLOU2 / Horizon budgets:** read through failed redactions. Outlets hedge slightly; ~$220M / ~$212M is the consensus reading.
- **Black Myth budget:** $43M (official tax-bureau quote) vs $70M (investor). Use "~$40–70M" or say "under $70M".
- **Developer headcount worldwide:** no census exists. 11.1M includes hobbyists, and professional estimates range from 230k to 1M+. Say "lakhs of professionals, crores of hobbyists" with a caveat.
- **Team composition %:** blog and teaching estimates only.
- **Epic valuation:** $22.5B was the last priced round. Lower figures (~$10.8B) are secondary-market estimates.
- **GTA 6 copies sold (17.07M, Sensor Tower)** appeared in one launch-week article. [U]
- **Not covered (budget ran out):** Nintendo revenue and headcount, Tencent and Sony market caps, Krafton market cap and headcount, projected job-growth numbers, demand for specific roles.
